## Installation

Clone the repository:

```bash
git clone https://github.com/NattiiZ/OnlineShop-frontend_jsProj.git
cd OnlineShop-frontend_jsProj
```

Install dependencies:

```bash
npm install
```

## Environment Configuration

Create a `.env` file in the project root directory.

Example:

```env
HOST_PORT=3000
API_PORT=5000

SECRET_KEY="9999"
```

### Environment Variables

| Variable   | Description                       | Default |
| ---------- | --------------------------------- | ------- |
| HOST_PORT  | Frontend server port              | 3000    |
| API_PORT   | Backend API port                  | 5000    |
| SECRET_KEY | Secret key for session management | 9999    |

You can modify these values according to your environment.

## Run Application

Start the frontend server:

```bash
npm start
```

The application will be available at:

```text
http://localhost:3000
```
