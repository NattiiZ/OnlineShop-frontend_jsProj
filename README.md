# OnlineShop Frontend

A frontend e-commerce web application developed as part of a **JavaScript Project** course. The application provides a simple online shopping experience by consuming data from a RESTful API.


## Features

* Product listing
* Product details
* Search products
* Product categories
* Shopping cart
* User authentication (Login/Register)
* Session management
* REST API integration

## Tech Stack

* HTML5
* CSS3
* JavaScript
* Node.js
* Express.js
* Axios

## Installation

```bash
git clone https://github.com/NattiiZ/OnlineShop-frontend_jsProj.git
cd OnlineShop-frontend_jsProj
npm install
```

Create a `.env` file:

```env
RukCom_IP=http://localhost:3000
```

Run the application:

```bash
npm start
```
